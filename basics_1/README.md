# Networking basics #1

This directory contains solutions for the Holberton School Networking basics #1
project. The tasks cover localhost, the hosts file, active IPv4 addresses, and
listening for connections with Netcat.

## Requirements

- Ubuntu 22.04 LTS
- Bash scripts begin with `#!/usr/bin/env bash`
- Bash scripts have a comment on the second line
- Bash scripts are executable and pass ShellCheck

## Tasks

- `0-change_your_home_IP` - configure localhost and facebook.com in `/etc/hosts`
- `1-show_attached_IPs` - display active IPv4 addresses
- `2-port_listening_on_localhost` - listen on localhost port 98 with Netcat

## Usage

```bash
sudo ./0-change_your_home_IP
./1-show_attached_IPs
sudo ./2-port_listening_on_localhost
```
