# Networking basics #0

This directory contains solutions for the Holberton School Networking basics #0
project. The tasks cover the OSI model, network types, addresses, transport
protocols, ports, and ICMP.

## Requirements

- Ubuntu 22.04 LTS
- Answer files contain one answer number per line
- Bash scripts begin with `#!/usr/bin/env bash`
- Bash scripts have a comment on the second line
- Bash scripts are executable and pass ShellCheck

## Tasks

- `0-OSI_model` - answer questions about the OSI model
- `1-types_of_network` - identify LAN, WAN, and Internet networks
- `2-MAC_and_IP_address` - answer questions about MAC and IP addresses
- `3-UDP_and_TCP` - compare TCP and UDP behavior
- `4-TCP_and_UDP_ports` - display listening TCP and UDP ports
- `5-is_the_host_on_the_network` - ping an IP address five times

## Usage

```bash
./4-TCP_and_UDP_ports
./5-is_the_host_on_the_network 8.8.8.8
```
